What is and isn't backed up

New snapshots capture persistent and temporary app data plus private app definitions and API-key verifier records in the same encrypted snapshot. Standard mounts do not include the router database or host SSH keys. Archive data and the backup app's own storage are excluded. Backups read live files: arrange application-consistent database backups when needed.

Restic configuration

The password used to encrypt the backup. You will need this password to restore from your backups, so make sure to keep it safe.

Retention policy

After each successful backup, old snapshots are expired using restic's forget policy. A snapshot is kept if it matches any rule below. Leave a field at 0 to disable that tier. If every field is 0, nothing is expired (all snapshots are kept). The space freed by expired snapshots is reclaimed by a prune that runs in the background afterwards.

Details about migration
This instance: The backend validates the target and captures configuration and desired states before pausing all non-backup apps that may write shared data, including unselected apps. Selected apps remain stopped after cutover; previously running unselected apps resume during cleanup. Source app data is not modified or deleted.

Destination: The encrypted snapshot is transferred and verified before apps are stopped. The ordinary backup restore then replaces selected data, imports keys, restores providers and grants, and waits for app readiness. Other apps retain data and are restarted afterward.

Limits: Owner password, sessions and platform settings are not transferred. Provider-scoped OAuth approvals require manual reauthorization and make recovery incomplete. Existing app sources and published ports must match. Both existing and newly installed apps start during recovery before saved stopped states are applied; they can run while other apps become ready. {% for entry in scope.excluded if entry.user_facing and entry.reason %} The path {{ entry.path }} is also excluded from the snapshot pipeline. {{ entry.reason }} {% endfor %} See the Backups tab for the full list.
